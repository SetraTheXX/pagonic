# Code of Conduct

Pagonic is a learning-driven open-source project. Contributors, reviewers, and
maintainers are expected to make technical collaboration safe and welcoming.

## Expected Behavior

- Be respectful, specific, and constructive.
- Assume good intent while discussing code and design decisions.
- Explain disagreement with evidence, tests, or a clear trade-off.
- Welcome questions from contributors with different levels of experience.
- Keep security reports private until coordinated disclosure is appropriate.

## Unacceptable Behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing private information without consent.
- Deliberate disruption of issues, pull requests, CI, or releases.
- Sharing exploit details or credentials in public project spaces.
- Misrepresenting benchmark results, security status, or project capabilities.

## Enforcement

Report concerns privately to the repository maintainer through GitHub. Security
vulnerabilities should follow [SECURITY.md](SECURITY.md), not a public issue.
The maintainer may edit, close, or remove contributions that violate this code
of conduct and may restrict participation when necessary to protect the
project community.

This document is a practical project policy and may be refined as the
contributor community grows.
